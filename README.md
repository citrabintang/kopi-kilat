# Kopi Kilat

Website Kopi Kilat berupa HTML, CSS, JavaScript, dan aset gambar statis.

## File website

File website berada di root repositori: `index.html`, `style.css`, `app.js`, dan folder `assets/`.
Buka `index.html` untuk melihat website secara lokal.
Untuk hosting statis, gunakan root repositori sebagai direktori publik. Tidak diperlukan proses build.

## Status

Versi demo prapeluncuran. Menu dan harga masih contoh; kontak WhatsApp belum aktif.
