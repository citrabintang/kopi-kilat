# Kopi Kilat

Website Kopi Kilat berupa HTML, CSS, JavaScript, dan aset gambar statis.

## File website

Semua file website berada di `website/`.
Buka `index.html` di folder tersebut untuk melihat website secara lokal.
Untuk hosting statis, gunakan folder tersebut sebagai direktori publik. Tidak diperlukan proses build.

## Status

Versi demo prapeluncuran. Menu dan harga masih contoh; kontak WhatsApp belum aktif.
Dokumen bisnis dan desain di luar folder website tidak disertakan dalam repositori.
